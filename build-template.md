# Website Build Brief

## 1. Project Overview

Describe the website, its purpose and its audience.

## 2. Design Reference

Use the designated Figma frame as the primary visual reference.

Inspect the design using the available MCP tools before implementation.

Identify the Figma file and intended page frame.

Describe the vertical design information available.

## 3. Page Structure

Identify the sections in the figma design, in order.

List each section.

Document:
- Purpose.
- Content.
- Layout.
- Typography.
- Colours and background.
- Assets.
- Important spacing and alignment.
- Its relationship to adjacent sections.

## 4. Design System

Document the verified:
- Colour palette.
- Typography.
- Spacing.
- Content widths.
- Grid and alignment.
- Buttons and other interface components.

Document the colours, typography, spacing, content widths, buttons and reusable components.

## 5. Assets

List the required layers, logos, icons, and fonts.

Indentify the intended use of each asset.

## 6. Technical Requirements

Specify HTML, CSS, Javascript, file organization, accessibility, and any neccessary interactions.

## 7. Responsive Behaviour

Describe the intended desktop, tablet, and mobile layout.

## 8. Acceptance Criteria

List the visual, technical, responsive, and functional requirements for completion.

## 9. Outstanding Questions

The site must:
- Include every required design section.
- Use the correct available assets.
- Match the design's visual heirarchy.
- Work at different viewport widths.
- Have no broken local asset references.
- Be reviewed in a browser before completion.
