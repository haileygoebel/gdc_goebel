# Project Instructions

## Project Purpose

Build a new, respnonsive, single-page website based on a supplied Figma design.

The website must reflect the intended visual heirarchy, layout, typography, colour palette, and content structure of the design.

## Before Development

- Read, BUILD.md before implementing the website.
- Inspect the designated Figma design using the available MCP tools.
- Identity the required page sections and assets.
- Review design information before writing any code.
- Indentify missing information before making significant assumptions about the design.

## Development Standards

- Use semnatic HTML5.
- Use maintainable CSS.
- Use Javascript only when required.
- Use Flexbox and Grid where appropriate.
- Reuse design assets and components where available.
- Avoid unnecessary frameworks and dependencies.
- Follow accessible web development practices.

## Responsive Design

- Support desktop, tablet, and mobile layouts.
- Preserve the content heirarchy at small widths.
- Prevent horizontal overflow.
- Ensure text and interactive elements remian usable.

## Quality Control

- Compare the finished website with the Figma design.
- Check image paths and stylesheet references.
- Inspect the website at different viewport widths.
- Report unverified details honestly.
